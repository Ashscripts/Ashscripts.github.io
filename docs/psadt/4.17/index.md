## About This Section

This section contains PSADT 4.17 references and reusable deployment examples for application packaging and deployment.

The scripts cover common PSADT operations including:

* Active Setup configuration.
* Registry key creation and removal.
* Common PSADT 4.17 variables.
* File and folder copying.
* Copying files to existing user profiles.
* Process execution.
* MSI installation, patching, and uninstallation.
* Installation prompts and application closing.
* Deployment deferral handling.
* Disk-space validation.

Each script page contains the relevant PSADT source code from the original script collection, organized into a dedicated topic for easier reference and reuse.
