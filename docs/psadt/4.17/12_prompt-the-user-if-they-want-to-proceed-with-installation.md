# Prompt the user if they want to proceed with installation:

```powershell
Show-ADTInstallationPrompt -Message 'Do you want to proceed with the installation?' -ButtonRightText 'Yes' -ButtonLeftText 'No'
#reference link:https://psappdeploytoolkit.com/docs/4.1.x/reference/functions/Show-ADTInstallationPrompt
```
