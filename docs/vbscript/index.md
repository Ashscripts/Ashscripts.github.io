# VBScript Scripts

A collection of reusable VBScript scripts for Windows administration, registry operations, file and folder monitoring, Windows Installer troubleshooting, application automation, and deployment tasks.

## Scripts

### Registry Operations

- [Registry Existence Monitor and Delete](01_vbscript-to-search-for-a-registry-existence-for-every-1-sec-and-delete-as-soon-as-found.md)

Continuously checks for a specific registry value and deletes it as soon as it is detected.

### File and Folder Monitoring

- [Wait Until Folder or File Is Found](02_wait-until-the-folder-is-found-or-created-at-runtime-vbscript.md)

Waits for a specified file to appear inside a folder before continuing execution.

### VBScript Reference

- [VBScript Reference](03_vbscript-reference.md)

Common VBScript examples covering environment variables, registry operations, folder creation, file copying, shortcuts, and text replacement.

### Windows Installer

- [Source Resiliency Fix](04_source-resiliency-fix.md)

Uses the Windows Installer API to add an installation source and force source-list resolution for a product.

### Application Automation

- [AutoIT VBScript](05_autoit-vbscript.md)

Automates an application installation using HTA, MSI, window detection, and `SendKeys`.

## About This Section

This section contains standalone VBScript examples that can be used for Windows administration, application deployment, troubleshooting, and automation.

Each script page contains the relevant VBScript source code from the original script collection, organized into a dedicated topic for easier reference and reuse.
