# Ashscripts

A collection of practical scripts, automation examples, deployment references, and Windows administration utilities.

## Documentation

### PowerShell

Reusable PowerShell scripts for Windows administration, software management, registry operations, SCCM/MECM, Intune, troubleshooting, automation, and application packaging.

[Open PowerShell Generic Scripts](powershell/generic-scripts/index.md)

### PSADT

PowerShell Application Deployment Toolkit (PSADT) 4.17 scripts and references for application deployment, installation, uninstallation, registry configuration, file operations, MSI operations, prompts, and deployment validation.

[Open PSADT 4.17 Scripts](psadt/4.17/index.md)

### VBScript

A collection of VBScript examples for registry monitoring, file and folder detection, Windows Installer source resiliency, application automation, and installation workflows.

[Open VBScript Scripts](vbscript/index.md)

## About Ashscripts

Ashscripts is a personal collection of reusable Windows administration and application deployment scripts.

The documentation is organized by scripting technology and deployment framework so that individual scripts can be found and reused quickly.
